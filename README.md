Course: Skill Wallet Data Visualization Project  

## Project Overview
This project focuses on analyzing heart disease data to identify major health factors that contribute to cardiovascular diseases. The analysis helps in understanding patterns in patient health records and identifying individuals who may have a higher risk of heart disease.

The dataset includes various medical attributes such as age, gender, cholesterol levels, chest pain type, and maximum heart rate. Using data visualization techniques, these attributes are analyzed to discover meaningful insights.

## Tools Used
- Tableau  
- Python  
- Heart Disease Dataset  

## Dataset Description
The dataset contains patient medical information including:

- Age  
- Gender  
- Chest Pain Type  
- Resting Blood Pressure  
- Cholesterol Level  
- Maximum Heart Rate  
- Exercise Induced Angina  

These attributes are used to determine whether a patient is likely to have heart disease.

## Key Insights
- People between the age group of **50–60 years** show a higher risk of heart disease.
- Male patients tend to have a higher probability of heart disease compared to females.
- High cholesterol levels may increase the chances of cardiovascular disease.

## Conclusion
This project demonstrates how data analysis and visualization can help identify patterns in healthcare data. By analyzing patient health indicators, we can better understand the factors that contribute to heart disease and support early detection.
